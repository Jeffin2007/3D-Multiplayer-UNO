name: UNO deck composition
description: Resolves the conflicting action-card copy counts in the UNO Arena game brief.
---

Use two copies per color for Skip, Reverse, and Draw Two cards. The brief says “8 cards (one per color)” for each action, but four colors with one each would produce only four cards; two copies per color preserves the stated 108-card total and standard UNO deck composition.

**Why:** the requested total deck size is explicit and matches the standard 108-card distribution.

**How to apply:** keep two of each colored action card unless the user explicitly changes the total deck size or clarifies a different copy count.
